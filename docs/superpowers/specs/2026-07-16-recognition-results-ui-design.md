# 辨識結果 UI 設計

## 目標

- 將辨識結果由 3 秒浮層改為相機與按鈕之間的固定區域。
- 讓多筆結果逐行顯示，並將介面與狀態文字中文化。
- 維持目前相機高度、TensorFlow 模型與辨識流程。

## 採用方案

在約 250px 高的白色控制區中，上方放置「辨識結果」區，下方保留辨識按鈕。模型回傳的候選結果逐行顯示為 `英文類別　信心值%`；不加入翻譯服務或類別字典。

## 顯示狀態

- 初始：`辨識結果會顯示在這裡`
- 執行中：`辨識中…`
- 成功：逐行顯示模型回傳結果，信心值改為百分比。
- 失敗：`辨識失敗，請再試一次`

辨識執行期間停用按鈕，完成或失敗後恢復，避免連續點擊重複啟動相機擷取與推論。

## 實作範圍

- 僅調整 `www/index.html` 的結果標記、樣式與既有辨識回呼。
- 不再呼叫 `smallComment` 顯示辨識結果。
- 將頁面標題等目前可見的介面文字改為繁體中文。
- 不翻譯 ImageNet 英文類別名稱，也不新增依賴。

## 驗證

- 最小自動檢查確認固定結果區存在，且辨識流程不再呼叫 `smallComment`。
- 在已連接手機上執行 App，確認初始、辨識中、成功與可再次辨識的狀態，並檢查結果位於相機與按鈕之間。
